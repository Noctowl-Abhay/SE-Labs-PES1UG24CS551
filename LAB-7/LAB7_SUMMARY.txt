-------------------------------------------------
BUGS FOUND (before the fix)
-------------------------------------------------
sanitize_license_plate   AttributeError: 'NoneType' object has no
                         attribute 'strip'   (plate = None)
parse_trip_mileage       AttributeError: 'NoneType' object has no
                         attribute 'split'   (mileage_csv = None)
format_rental_invoice    AttributeError: 'NoneType' object has no
                         attribute 'split'   (record = None)

Root cause: none of the functions checked the type of their input,
so None reached a string method (.strip / .split) and crashed.

-------------------------------------------------
FIXES APPLIED IN processor.py
-------------------------------------------------
sanitize_license_plate
  - None or non-string input -> returns "" instead of crashing.
  - Strips whitespace, removes '-', ' ', '_', '#', then uppercases.
parse_trip_mileage
  - None or non-string input -> returns [].
  - Each piece is stripped; empty pieces are skipped.
  - A piece that is not a number (ValueError) is skipped, so
    "10, abc, 20" gives [10.0, 20.0].
format_rental_invoice
  - None or non-string input -> "Invalid Record".
  - Fewer than 3 ':'-separated fields -> "Invalid Record Format".
  - Days that is not an integer falls back to 0.
  - Category "suv" (any case) is 50.0/day, everything else 30.0/day.

-------------------------------------------------
OBSERVATIONS
-------------------------------------------------
- All three failures came from the same input, None. The st.none()
  part of the strategy found it straight away; plain st.text() alone
  would not have.
- The tests follow the "it should not crash" property, so they check
  robustness, not correctness of the output.
- Hypothesis shrinks a failing input to the smallest case, which is
  why the report shows a clean s = None instead of a long random
  string.
- Things the current fix still allows (the tests do not catch them,
  since nothing crashes): negative days give a negative invoice
  total, and float() accepts values like "nan" and "inf" in
  parse_trip_mileage.
